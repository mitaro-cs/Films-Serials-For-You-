Nova Night Light

NovaNightLight.exe is built from desktop/night-light/NovaNightLight.cs.
MysticLight_SDK_x64.dll is the signed MSI Mystic Light SDK 1.0.0.08.
Source: https://download.msi.com/uti_exe/Mystic_light_SDK.zip
Documentation: https://storage-asset.msi.com/files/pdf/Mystic_Light_Software_Development_Kit.pdf
Publisher: MICRO-STAR INTERNATIONAL CO., LTD.

Requires a compatible installed MSI Mystic Light application.
Only supported LED brightness is changed. Original values are stored before
changes in the Nova user data directory, night-light.json, for restoration.
Unsupported zones and physical power/status indicators cannot be switched off.
SDK timeout or unsupported hardware is reported to the user, never treated as success.
