# Проверка Nova 1.0.0-beta.7

Дата: 21 октября 2026 года. Windows x64, локальная сборка NSIS.

## Что изменено

- Сведения карточки сохраняются до загрузки обложек, кадров и похожих работ. Изображения идут отдельными запросами через ограниченный загрузчик и кэш. При потерянном файле или недоступной старой обложке выполняется поиск замены по точному IMDb ID; неудачный запрос временно не повторяется.
- Сохранённая поисковая выдача появляется сразу, новые результаты дополняют её без перестановки уже показанных карточек. TVMaze дополняет поиск сериалов и данные сезонов, серий и иллюстраций. Каталоги связываются по IMDb ID.
- Вверху страницы фильма — баннер и беззвучный трейлер с кнопками паузы и звука. Информация и действия находятся ниже. Трейлер загружается отложенно, останавливается за пределами экрана и в скрытой вкладке; не попадает в историю просмотра фильма.
- Трекер серии показывает сезон, серию и остаток времени без ряда мелких сегментов. После завершённой серии выбирается следующая, в том числе следующий сезон.
- Убраны снимки View Transitions и проявление секций по scroll timeline. Оставлены короткие переходы opacity/transform и анимации нажатия. HLS начинает воспроизведение в адаптивном режиме, с ограниченным буфером и выбором качества по размеру плеера.
- Поиск видео учитывает произведение, год, сезон и серию. Первая серия не совпадает с десятой; полнометражный фильм и трейлер не предлагаются вместо серии. Ошибка нативного потока не открывает iframe автоматически.
- Добавлен поиск MP4 Internet Archive с отметкой Public Domain. Запросы к провайдерам выполняются параллельно и ограничены по времени. VK использует существующий ключ хоста. Dailymotion не включён в выдачу: metadata отвечала, но CDN вернул 403.

- Автопереход к следующей внешней серии с отсчётом, отменой и переходом между сезонами по метаданным. Следующий источник ищется ближе к концу просмотра. Просмотренные серии выделены подписью, заполненной галочкой и приглушённым кадром; список следует за текущей серией.
- Клавиша F синхронизирует Fullscreen API с настоящим полноэкранным окном Tauri на Windows. При смене внешней серии сохраняется элемент видео и полноэкранный режим.
- Кнопка показа пароля во всех формах. Добавлены подтверждённая почта, восстановление одноразовой ссылкой и настройки SMTP с предустановкой Gmail. Токены хранятся хешами SHA-256, действуют 15 минут; сброс завершает прежние сеансы на других устройствах. Неподтверждённый адрес не используется для восстановления. Настройка: [Gmail](gmail-setup.md).

## Проверки

- Svelte Check: 0 ошибок и предупреждений. Vitest: 14 пройдено. npm audit web и desktop: 0 известных уязвимостей на дату проверки.
- Clippy workspace/all-targets: без предупреждений. Rust: 58 модульных и 10 интеграционных тестов пройдены. Включены точный сосед серии, переход к следующему сезону, ограничение управления окном локальным входом, одноразовость/срок/назначение токена восстановления, отзыв сеансов и отсутствие SMTP-пароля в ответах API.
- Отдельный прогон новых сценариев: 21 из 21 — телефон, планшет и компьютер. Затем 6 из 6 проверок раскрытых настроек Gmail и раздела аккаунта.
- Реальные источники: 2 из 2 сетевых тестов. Rutube: получены и переписаны HLS-плейлисты, проксирован видеосегмент 204 920 байт; FFmpeg декодировал кадр фильма в PNG. TVMaze: фон и 12 серий первого сезона tt0159206. Internet Archive: поиск материала с отметкой Public Domain и Range-запрос MP4 с ответом 206, 4096 байт.
- Финальный единый браузерный прогон: 199 пройдено, 11 штатных пропусков, 0 ошибок (9,5 минуты). Проверены телефон, планшет и компьютер; дополнительный тест прошёл 40 сочетаний страниц и размеров 320×640, 844×390, 1024×700, 1920×1080, 2560×1440. Главная передаёт 76,2 КБ сжатого JavaScript при бюджете 80 КБ; hls.js на главной не загружается. В проверенных сценариях переходов CLS равен 0,0000.
- Ранее проверка геометрии ошибочно учитывала скрытые потомки закрытого details. Это подтверждено отдельно: Playwright isVisible=false, browser checkVisibility=false при сохранённой геометрии. Проверка исправлена; раскрытые SMTP-поля проверяются отдельным сценарием. Последний общий прогон выше выполнен уже с исправленной проверкой.
- Windows NSIS собран успешно. Версия программы: 1.0.0-beta.7. Проверено наличие в release EXE последних CSS настроек почты и поля пароля, нативного мостика fullscreen и схемы почты.

## Область проверки

Браузерные сценарии выполняются на изолированной базе с синтетическими фильмами, постерами и VP8-видео. Мобильные размеры проверяются в эмуляции Chromium; физический iPhone и мобильная сеть не проверялись. Тесты реальных источников запускаются отдельно и зависят от их текущей доступности. Наличие карточки в каталоге не означает наличие бесплатного видеопотока.

Поиск не гарантирует любой фильм, полную фильмографию или все обложки. При недоступном трейлере остаётся статичный баннер. Автозапуск может ограничиваться браузером. Проверка известных уязвимостей зависимостей не заменяет независимый аудит.

Реальная отправка через Gmail не выполнялась: адрес и пароль приложения владельца не предоставлялись. Проверены интерфейс и серверная логика восстановления на изолированных данных; SMTP использует lettre с TLS/STARTTLS. После ввода реквизитов в Nova нужно нажать «Проверить отправку». Физическое скрытие панели задач в установленном пользовательском окне не проверялось: проверены команда Tauri, локальные права и браузерная синхронизация F/Esc/смены серии. Текущее установленное приложение владельца не заменялось.

Установщик сохраняется в `target/release/bundle/nsis`; приложение автоматически не устанавливается.
