# Nova 1.0.0-beta.14

24 октября 2026. Локальная сборка Windows x64; установленное приложение и рабочая база не изменялись.

## Изменения

- Дизайн «Кинозал» (выбор владельца из трёх вариантов): большой кадр с белой «Смотреть» сверху главной
  и страницы фильма (на телефоне - `title/MobileHero` с кадром, сведениями, «+» и «…»), «Продолжить
  просмотр» - кадрами 16:9, «жидкое стекло» только на капсулах (шапка, разделы, круглые кнопки).
  Логотип сверху на телефоне убран, при входе - заставка (`ui/Intro.svelte`, раз за сессию; в автотестах
  и без анимаций - нет).
- Жанры: `meta::genre_ru`/`genres_ru` - один русский список для IMDb и Викиданных, запись в базу уже
  нормализованная, сохранённое приводится при запуске (`normalize_stored_genres`).
- Совместный просмотр: элементы комнаты раскладываются по высоте панелей плеера (`--top-h`, `--bottom-h`),
  «Смотреть одному», «Смотреть вместе» в окне «Смотреть по ссылке» (своя комната с любым видео).
- Плеер: отклик кнопок, смена значка «пуск/пауза». Нижняя панель: `overflow-x: clip` вместо `hidden`
  на html/body и свой слой - на iPhone не уезжает.
- Трейлеры: hls.js закрепляет лучший вариант от 720p, без 720p - кадр фильма.
- Автопоиск видео: оригинальное название и без года, сортировка по длительности и качеству.
- Аватарки - 12 своих персонажей (`ui/characters.ts`), новому - случайный. «Управление → Люди» - карточками.

## Проверено

- `cargo fmt --check`, clippy `-D warnings`, `cargo test -p fsfy-server` (в том числе нормализация жанров);
  Svelte check 0/0; Vitest 18; production build.
- Playwright на phone/tablet/desktop/iphone-webkit: полный прогон 294 passed, 30 skipped; найденное после
  исправления проверки вёрстки - перепроверено (`layout` + `selfcheck`: 101 passed, 3 skipped).
- Проверка вёрстки (`e2e/util.ts expectClean`) усилена: на время замера снимает обрезку html/body и
  учитывает собственный `overflow` элемента. Раньше `overflow-x` на body отключал проверку «за правым краем».
- Заставка не показывается в автотестах (`navigator.webdriver`) - иначе закрывала страницу от проверок.

## Границы

OK.ru и Дзен без входа не отдают результатов поиска (OK.ru показывает подборку популярного) - не
подключены. Больше всего фильмов даёт VK: нужен ключ `vk.token` в настройках. «Управление → Настройки»
целиком не перерисованы - только «Люди». Настоящий iPhone не проверялся.
