# Nova 1.0.0-beta.12

23 октября 2026. Локальная сборка Windows; установленное приложение и рабочая база не изменялись.

## Исправления

- Список участников учитывает просмотренные внешние фильмы. Локальная и внешняя копия с одинаковым IMDb ID считаются один раз; сериалы не считаются фильмами.
- Пустое оригинальное название больше не пропускает любые результаты поиска. Для однословных названий нужен точный год; «Животные (2026)» не совпадают с роликами о домашних животных 2025 года. Кэш трейлеров v3 отбрасывает ранее выбранные неподходящие видео.
- Сенсорный плеер: центральные пауза/пуск и ±10 секунд, совместное скрытие с интерфейсом, без блока актёров. Плавное появление основного интерфейса, отключаемое prefers-reduced-motion.
- Новый импорт в настройках окна хоста: страница фильма либо каталога, до 20 карточек и 2 сетевых запросов одновременно, повторные URL пропускаются. Таймаут 10 секунд, ответ до 4 MiB; запрет локальных адресов и DNS private IP. В каталог добавляются карточки со ссылками без обязательного локального файла.
- Из перебора встроенных плееров исключены URL с сегментами trailer/trailers/teaser, чтобы при недоступном фильме не запускать трейлер.

## Проверено

- 64 серверных unit-теста; clippy all-targets без предупреждений.
- Социальный HTTP-тест: внешний просмотр и отсутствие двойного счёта.
- Импорт: права локального хоста, запрет private URL; живой Gidonline на временной базе — добавление карточки, получение адреса потока, повтор без дубля. Проверено отклонение страницы сериала без импорта посторонних рекомендаций. Lordfilm /podborki/ — 20 карточек за один ограниченный запрос.
- Svelte: 0 ошибок и предупреждений; production build.
- 10 регрессионных браузерных проверок трейлера, внешних серий, fullscreen и ночного режима; 2 проверки формы импорта на телефоне и компьютере — прошли.
- Мобильный Chromium: пауза, перемотка через HTTP Range, скрытие управления; альбомный скриншот просмотрен. WebKit-воспроизведение пропущено из-за отсутствия VP8-декодера в тестовой среде, реальный iPhone не проверялся.

## Границы

Импорт не обходит сайт целиком: следующая страница подключается отдельным запросом. Только карточки с подтверждёнными названием/годом в H1 и встроенным плеером; сезоны не импортируются. Получение ссылки на поток не подтверждает декодирование всего фильма, русскую дорожку или качество. Kinoklass возвращает HTTP 403; обход блокировки не реализован. Если страница содержит только подборки, импорт проверяет ссылку на раздел /filmy/, /films/ или /movies/.

В Java preview дополнительно перенесены GET /api/members и POST/DELETE /api/friends/{id}; сборка и HTTP-проверки проходят. Всего 27 маршрутов перенесены, 3 частично, 109 ожидают переноса. Java остаётся отдельным preview; основной установщик использует Rust-сервер. Полный перенос, 50 реальных видеосеансов через интернет и аппаратное выключение всей RGB-подсветки не подтверждены. Ограничения ночного режима и предыдущие проверки — в release-beta11-checks.md.
