# Nova 1.0.0-beta.11 — проверки и границы выпуска

Дата: 22 октября 2026. Установщик Windows собирается локально. Рабочая база и установленная Nova не изменялись.

## Изменения в основном приложении

- Трейлеры: новый кэш `trailer.ru.v2`, явные признаки русской озвучки вместо одного русского названия, исключение оригинала/субтитров. До четырёх кандидатов; HLS выбирает доступный HD-вариант до 1080p. SD-файл не показывается в баннере. Название источника само по себе не является акустической проверкой озвучки.
- Для «Крёстного отца» закреплён [дублированный трейлер КГ-Портала](https://kg-portal.ru/movies/godfather/trailers/). ffprobe подтвердил 1920×1080, 115.59 с. Старый английский кэш не используется.
- Ночной режим: Управление → Настройки; также пункт трея «Погасить экран · сайт работает». Через три секунды окно скрывается, Windows получает команду отключить дисплей. Существующая защита от автоматического сна остаётся активной; при ошибке её создания команда отклоняется. Системный план питания не изменяется. Запрос доступен только локальной сессии окна хоста.
- Дополнительный мост MSI Mystic Light: диагностика поддерживаемых зон, сохранение исходной яркости до изменений, установка нулевой яркости, восстановление. Не управляет физическими индикаторами и неподдерживаемыми устройствами. SDK запускается отдельным ограниченным по времени процессом без окна.

## Проверки

- `cargo test -p fsfy-server`: 79 прошли, 6 ранее обозначенных opt-in тестов пропущены. В том числе реальные ffmpeg, Range, HLS, 10/50 участников комнат, отзыв сессий, ограничения локального ночного API и замена старого кэша трейлера.
- `cargo clippy --workspace --all-targets -- -D warnings`: успешно.
- Svelte check: 0 ошибок и предупреждений. Vitest: 18 тестов, 8 файлов — успешно. Production web build — успешно.
- Playwright: HD-трейлер, ручная пауза, ошибка источника и переключение серий/F — 6 успешных проверок на phone/desktop. Проверка ночного интерфейса сначала обнаружила скрытие текста ошибки; после исправления 8 проверок night-beta11 прошли на iphone-webkit/phone/tablet/desktop.
- Проверки браузера ночного режима подменяют аппаратный ответ: они не выключали реальный экран и не меняли подсветку во время работы пользователя.
- На реальном компьютере найдены MSI MAG B760 TOMAHAWK WIFI и Mystic_Light_Service. Подпись DLL MSI валидна. Read-only вызов SDK: Initialize успешен, GetDeviceInfo вернул -2 (тайм-аут). Поэтому **отключение RGB на этом компьютере не подтверждено**; ошибка показывается пользователю.
- Показатель 420.8 Мбит/с из beta.10 относится к прежнему испытанию на localhost, не является новым испытанием через интернет или гарантией для 50 физических устройств. Код потоковой раздачи в этом выпуске не заменён.

## Java

Перенос остаётся незавершённым: 25 из 138 маршрутов перенесены, 3 частично, 110 ожидают переноса. Установщик содержит рабочий Rust-сервер, а не Java preview. Подмена не выполнялась.

В Java добавлены Range/скачивание/изображения, управление аккаунтами и отзыв сессий, локальный каталог и статусы, сохранение прогресса и маркеры. `server-java/build.ps1` с `-Xlint:all -Werror` успешно проверяет временную базу, совместимость хешей, HTTP-права, статусы, русскоязычный поиск, Range и 50 параллельных небольших диапазонов. Это не подтверждение готовности Java к полной замене приложения.
