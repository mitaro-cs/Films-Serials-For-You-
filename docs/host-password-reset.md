# Сброс пароля без почты

В beta.8 основной способ восстановления — через владельца Nova. Gmail и SMTP не нужны.

1. Зритель сообщает владельцу свой логин.
2. Владелец открывает **Управление → Люди → Сбросить пароль** рядом с нужным человеком.
3. После подтверждения Nova создаёт случайный пароль из 18 символов. Пароль показывается только после успешного ответа сервера. Его можно скопировать, передать человеку лично и скрыть.
4. Зритель входит с новым паролем и меняет его в **Я → Аккаунт**.

Сброс завершает прежние сеансы пользователя и отзывает старые ссылки восстановления и подтверждения почты. Прогресс, списки и избранное сохраняются. Зритель не может сбрасывать пароли через административный API. Пароль самого хоста нельзя менять через этот API из удалённого сеанса.

Если SMTP уже настроен, на странице восстановления остаётся дополнительный раскрывающийся способ через почту. Он не требуется для сброса владельцем.
