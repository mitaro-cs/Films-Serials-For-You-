# Nova 1.0.0-beta.8

Дата: 21 октября 2026 года. Windows x64, NSIS.

## Изменения

- Safari получает список разрешений из HLS master playlist. Ручное качество выбирается сервером: сохраняются группы озвучки и ссылки на ключи/сегменты. «Авто» возвращает исходный master. При смене сохраняются позиция и пауза. Не объявленные источником разрешения не выдумываются. Прямые публичные HLS-ссылки также используют этот выбор; сервер проверяет адреса и DNS и не получает доступ к внутренней сети.
- Карточки локальных и внешних фильмов на телефонах до 640 px используют одну колонку: постер, информация и действия не накрывают друг друга. Длинные заголовки и значения переносятся.
- Меню плеера учитывает ширину экрана, безопасные поля iPhone, ограничивает высоту и прокручивается. Высота строк меню не меньше 44 px.
- Media Session получает название видео и отдельную квадратную иллюстрацию с непрозрачным чёрным фоном. Иконки PWA и Apple Touch также без прозрачных углов; чёрный пиксель в углах подтверждён для всех четырёх PNG.
- Основное восстановление — через владельца, без SMTP. В «Управление → Люди» есть подписанная кнопка сброса, криптографическая генерация нового пароля, показ после успешного ответа, копирование и скрытие. Сервер отзывает сеансы и прежние recovery-токены. Почтовый способ остался дополнительным при настроенном SMTP.

## Проверки

- Svelte Check: 0 ошибок и предупреждений; Vitest: 16 успешных тестов.
- Rust: 59 unit-тестов и 11 интеграционных тестов; сетевые проверки по умолчанию исключены. Clippy workspace/all-targets с запретом предупреждений пройден.
- Новый набор мобильных сценариев: 20 успешных проверок (WebKit iPhone, Chromium phone/tablet/desktop), включая выбор качества Rutube/прямого HLS и сброс владельцем.
- Настоящий поток Rutube: master с параметром height возвращает только выбранное разрешение; вложенный плейлист и видеосегмент 204920 байт получены. TVMaze: фон и 12 серий подтверждены.

- Общий прогон Chromium phone/tablet/desktop: **211 passed, 11 skipped, 0 failed**, 10.7 минуты. Включены 40 сочетаний страницы и размера от 320×640 до 2560×1440; нагрузка 32 клиента/640 запросов завершилась без ошибок (синтетическая тестовая библиотека).
- Дополнительный общий WebKit iPhone: **31 passed, 1 skipped, 0 failed**, 1.6 минуты.
- После финального расширения выбора качества на прямые HLS повторно выполнены затронутые сценарии: **36 passed** в Chromium и **7 passed** в WebKit; Rust unit/recovery и Clippy повторно пройдены.
- Настоящий прямой HLS Mux: сервер оставил варианты 720p и успешно отдал вложенный медиаплейлист. Финальный сетевой набор из трёх тестов (Mux, Rutube/TVMaze, Archive) полностью пройден.
- npm audit production: 0 уязвимостей.
