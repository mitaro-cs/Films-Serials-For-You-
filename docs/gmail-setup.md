# Gmail для восстановления пароля Nova

С beta.8 почта необязательна: основной способ — [сброс владельцем Nova](host-password-reset.md). Настройки ниже нужны только для дополнительного восстановления через подтверждённый адрес.

1. В аккаунте Google включите двухэтапную аутентификацию и создайте пароль приложения Nova: [страница Google](https://myaccount.google.com/apppasswords). Это отдельный пароль приложения, а не обычный пароль Gmail. [Инструкция Google](https://support.google.com/accounts/answer/185833?hl=en-GB).
2. В Nova откройте **Управление → Настройки → Почта и восстановление доступа**. Укажите Gmail отправителя и пароль приложения, включите отправку и сохраните настройки. Предустановлены `smtp.gmail.com`, TLS и порт 465. Также поддержан STARTTLS на порту 587.
3. Укажите адрес для тестового письма и нажмите **Проверить отправку**. Реальная отправка через ваш Gmail требует ваших настроек; в сборке нет чужой почты или встроенного пароля.
4. Для доступа друзей из интернета задайте доступный им публичный адрес Nova в дополнительных параметрах. Если поле пустое, ссылки используют текущий публичный адрес Nova, затем адрес локальной сети.
5. В **Я → Аккаунт → Почта для восстановления** укажите свою почту, подтвердите изменение текущим паролем Nova и перейдите по ссылке в письме. До подтверждения новый адрес не заменяет прежнюю подтверждённую почту.
6. При забытом пароле нажмите **Забыли пароль?** на экране входа. После перехода по ссылке задайте новый пароль. Ссылка одноразовая и действует 15 минут; прежние сеансы на других устройствах закрываются. Без заранее подтверждённого адреса восстановление по почте недоступно.

SMTP-пароль не возвращается API и не показывается после сохранения. Одноразовые коды хранятся в базе только как SHA-256. Код ссылки находится во фрагменте URL и не передаётся серверу при открытии страницы. Страница подтверждения не расходует ссылку до нажатия кнопки — автоматическая проверка ссылки почтовым клиентом не подтверждает адрес за пользователя.
