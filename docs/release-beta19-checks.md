# Nova 1.0.0-beta.19

25 октября 2026. Локальная сборка Windows x64; установленное приложение и рабочая база не изменялись.

## Изменения

- Страница фильма и сериала на телефоне - по макету (Fallout, белый вместо синего): `title/MobileHero`
  (кадр, «назад», звук трейлера, название одной строкой через `fitTitle`, плашки оценки и статуса,
  сведения через промежутки, описание, белая кнопка на всю ширину, «Трейлер / Оценить / Сохранить /
  Поделиться»). Шапка сайта на `/title` и `/ext` на телефоне скрыта (`header.detail`).
- В кадре - `TrailerBanner` в режиме `bare` (без своих кнопок; `available`, `muted` и `toggleSound()`
  наружу), HD-трейлер стартует с 8% (до 10 с), фон прозрачный - пока грузится, виден постер (`fallback`).
- Сериалы (`SeriesHero slim`): на телефоне верх скрыт, сезоны - вкладками «Сезон N» с белой чертой
  без прокрутки страницы, серии выбранного сезона - лентой кадров 16:9, галочка «посмотрел» рядом
  с названием (не поверх кнопки серии).
- Кадр IMDb на телефоне - 1280 px вместо 3840; страны и языки по-русски (`lib/countries.ts`).
- Проверка вёрстки: фон для проверки цвета текста запоминается (на «Топ-250» иначе не укладывалась в 30 с).

## Проверено

  (`catalog`, `episodes`, `mobile-beta8`, `layout`: 170 + 105 passed), `smooth` на планшете - 3 из 3,
