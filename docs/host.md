# Для хоста

## Первый запуск

1. Установите приложение и откройте его — окно сразу входит как **хост** (без пароля).
2. «Управление → Папки» → «Выбрать…» → папка с фильмами (можно несколько, можно внешний диск).
   Через минуту появятся постеры и описания.
3. «Управление → Доступ» → «Ссылка для всех» → войдите в бесплатный аккаунт
   [cloudpub.ru](https://cloudpub.ru) (почта и пароль или ключ API — один раз). Появится
   постоянная ссылка вида `https://….cloudpub.ru`: она открывается в России и с VPN, и без, и не
   меняется между запусками. Запасной вариант — fxTunnel (`https://kino-ab12c.fxtun.ru`).
4. «Управление → Люди» → «Пригласить» → отправьте ссылку другу. Он придумает логин и пароль и
   сразу смотрит.

Закрыли окно — сайт продолжает работать (значок в трее / строке меню). «Выключить сайт и
выйти» — в меню значка. Пока приложение работает, компьютер не засыпает (экран — может).

## Каталог: «Хочу посмотреть», «Смотрю», «Просмотрено»

Главная — разделы «Фильмы», «Сериалы», «Новое» и карточки-билеты: низ карточки — в цвет
постера, на ней страна, режиссёр, жанры и длительность. Кнопка в углу постера — статус:
«Хочу посмотреть» или «Просмотрено» (досмотренное становится белым билетом с датой и
штрихкодом). «Смотрю» ставится само, как только начали; где остановились — полоска на постере,
«осталось N мин» и ряд «Продолжить» сверху. Досмотрели фильм или все серии — «Просмотрено» само.
У каждого профиля статусы свои. Страну и режиссёра можно поправить: «Каталог → Изменить».

## Обновления

Приложение само проверяет новые выпуски на GitHub (через 20 секунд после запуска и раз в 6
часов) и спрашивает «Обновить сейчас?»; вручную — «Проверить обновления» в меню значка. Сайт
выключается на минуту, приложение ставит новую версию и запускается заново.

Для разработчика: обновления подписываются ключом. Секрет репозитория
`TAURI_SIGNING_PRIVATE_KEY` (Settings → Secrets and variables → Actions) — содержимое
приватного ключа, открытый ключ — в `desktop/src-tauri/tauri.conf.json`. Без секрета выпуск
собирается, но без файлов автообновления (`latest.json`). Потеряли ключ — новый ключ, новый
открытый ключ в конфиг, и обновлять уже установленные версии придётся вручную один раз.

## Профили и детский режим

У каждого аккаунта — до 6 профилей («Кто смотрит?» при входе на новом устройстве). Детский
профиль показывает мультфильмы и то, что до 12+; возраст берётся из описания, поправить —
«Управление → Каталог → Изменить → Возраст».

## Заставка и титры

Если в файле есть главы «Opening/Intro/Заставка» и «Ending/Credits/Титры», кнопка «Пропустить
заставку» и следующая серия на титрах появятся сами. Иначе отметьте их один раз в плеере
(флажок вверху справа) — отметка действует на весь сезон.

## Как называть файлы

| Файл | Что получится |
|---|---|
| `Начало (2010)/Inception.2010.1080p.mkv` | фильм «Начало», 2010 |
| `Breaking.Bad.S01E02.mkv` | сериал, 1 сезон, 2 серия |
| `Кухня/2 сезон/Серия 7.mp4` | сериал «Кухня», 2 сезон, 7 серия |
| `Фильм.ru.srt`, `Subs/*.srt` | субтитры |
| `poster.jpg`, `fanart.jpg` рядом | свои постер и фон |

Если что-то разобралось не так — «Управление → Каталог»: «Найти» (выбрать описание вручную),
«Изменить» (название, год, фильм/сериал, свой постер), «Скрыть».

## Описания

По умолчанию — IMDb, ключ не нужен; сюжет у IMDb обычно на английском. Для русского сюжета
выберите в «Настройках» TMDB (бесплатный ключ на themoviedb.org) или Кинопоиск
(ключ api.kinopoisk.dev, 200 запросов в день).

## Форматы и качество

MP4 (H.264/AAC) браузер играет сам. Если у друга медленный интернет, плеер сам включит
«Авто»: видео перекодируется кусочками по 6 секунд в 1080p–360p под его скорость (нужен
ffmpeg). Кадры для полосы перемотки готовятся в фоне после добавления фильмов. MKV, AVI, AC3/DTS, несколько озвучек — через ffmpeg: сборка
выпуска кладёт его в установщик. Если его нет (в «Обзоре» будет подсказка) — Mac:
`brew install ffmpeg`, Windows: `winget install ffmpeg`. Видео в H.265 на Windows и старых браузерах перекодируется — это
нагружает процессор, одновременно перекодируется не больше двух.

## Где данные

Mac — `~/Library/Application Support/app.fsfy`, Windows — `%APPDATA%\app.fsfy`: база
`fsfy.db`, картинки `images/`, клиент туннеля `tools/`. Сами фильмы не копируются.
