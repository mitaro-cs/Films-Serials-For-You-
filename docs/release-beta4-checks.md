# Nova 1.0.0-beta.4 — проверка выпуска

Дата: 20 октября 2026 года. Платформа сборки: Windows x64.

## Файлы выпуска

Установщик: `C:\Maison\Nova\target\release\bundle\nsis\Nova_1.0.0-beta.4_x64-setup.exe`.

Приложение: `C:\Maison\Nova\target\release\fsfy-desktop.exe`. Поля Windows ProductVersion и FileVersion проверены: `1.0.0-beta.4`.

Команда упаковки: `node node_modules/@tauri-apps/cli/tauri.js build --bundles nsis` из каталога `desktop`.

Выпуск подготовлен локально в указанной папке; публикация на внешнем сервере и установка поверх пользовательской версии не выполнялись.

## Изменения

- Единое оформление каталога, поиска, профиля, совместного просмотра и управления хостом; раздел «Аниме».
- Выбор серии с отдельными источниками, превью и сохранением позиции просмотра. Заброшенные сериалы исключаются из продолжения просмотра.
- Обновлённый плеер: управление при движении мыши, индикация горячих клавиш, сохранение прогресса, выбор максимального доступного качества.
- Русский язык метаданных без предварительного показа английского описания; улучшенная загрузка фоновых изображений.
- Хронология связанных фильмов по доступным метаданным, сведения об участниках, правила использования и конфиденциальность.
- Мониторинг CPU, памяти и диска Windows. Защита сетевых загрузок от обращений к локальным адресам и DNS rebinding.

## Проверки

- Rust: 56 модульных и 7 интеграционных тестов, Clippy и проверка форматирования пройдены.
- Svelte: 0 ошибок и 0 предупреждений; 14 модульных тестов пройдены.
- Браузерные проверки охватывают телефон, планшет, компьютер, узкие и широкие окна, серии, плеер, совместный просмотр, поиск, профиль, административные страницы.
- Полный прогон Playwright против release-сервера: **160 пройдено, 11 пропущено, 0 ошибок**, 6,1 минуты. Пропуски предусмотрены условиями тестов: служебная фотосъёмка запускается отдельно, проверки нагрузки, безопасности, бюджета JavaScript и перебора размеров выполняются один раз в desktop-проекте.
- После финального исправления ширины превью: **3 из 3** повторных проверок серий пройдены против пересобранного release-сервера. Проверяется отсутствие пересечения изображения с текстом; снимки телефона и компьютера просмотрены вручную.
- Проверки безопасности охватывают доступ гостя и обычного пользователя к административным API, CSRF, изоляцию прогресса пользователей, некорректный прогресс, заголовки безопасности, обход путей и SSRF.
- Нагрузочный сценарий: 32 одновременных клиента, 640 запросов каталога/состояния/записи прогресса, затем 16 параллельных Range-загрузок видео.
- Результат нагрузки на этой машине: **0 ошибок**, 850 мс суммарно; p50 — 28 мс, p95 — 47 мс, максимум — 70 мс. Это локальные измерения API, а не задержка воспроизведения через Интернет.

## Границы проверки

Это автоматические проверки конкретных сценариев, а не независимый аудит безопасности или доказательство отсутствия всех ошибок. Нагрузочный сценарий не измеряет предельное количество зрителей и не имитирует массовое перекодирование 4K.

Качество сторонних видео зависит от доступных потоков. Заявление сайта о 4K не подтверждает наличие такого потока. Динамические, зашифрованные или защищённые DRM-плееры могут не импортироваться. Воспроизведение каждого фильма со сторонних сайтов не проверялось.

Если русские метаданные отсутствуют, интерфейс показывает русскую заглушку; исходные названия могут сохраняться. Хронология опирается на доступную последовательность и даты выпуска, а не гарантированно на внутреннюю хронологию каждой киновселенной.

Системные политики Windows не сбрасывались: блокирующие политики брандмауэра при диагностике не обнаружены. В `scripts/Enable-NovaFirewall.ps1` подготовлено отдельное обратимое правило для Nova в частной локальной сети; оно не применялось автоматически.
