# Nova 1.0.0-beta.17

24 октября 2026. Исправление задержки карточек после импорта.

- Постер и фон публикуются в БД сразу после их загрузки, до ожидания галереи,
  фотографий актёров и кадров серий. Дополнительные изображения догружаются как раньше.
- Ошибка отдельного фильма больше не прерывает обработку остальных записей текущей очереди.
  Пауза после неудачной партии уменьшена с 600 до 60 секунд.
- API карточки сообщает metadataPending; открытая страница обновляется раз в пять секунд,
  пока данные обрабатываются. Нет параллельных запросов; скрытая вкладка не опрашивает API,
  уход со страницы отменяет запрос, завершение обработки останавливает опрос.

Проверено: 68 серверных unit-тестов, clippy all-targets без предупреждений, Svelte check
без ошибок и предупреждений, production build. Браузерный тест подтверждает появление
готового описания на открытой странице и прекращение опроса после завершения.
Логи: target/loading-fix-*.log.

Скорость внешних поставщиков метаданных не гарантируется. Это исправление конкретных
задержек, а не доказательство устранения всех возможных причин медленной загрузки.
Рабочая база и установленное приложение не изменялись.
