# Nova 1.0.0-beta.18

24 октября 2026. Локальная сборка Windows x64; установленное приложение и рабочая база не изменялись.

## Изменения

- Управление: `admin/Overview.svelte` - сводка «всё в порядке / нужно внимание», чек-лист состояния
  (сервер, доступ, ffmpeg, папки, описания, диск, версия) с пояснениями и ссылками на разделы, цифры
  с объяснением, нагрузка компьютера полосками (`transform: scaleX`, без перестройки), «Сейчас смотрят»
  с местом. Опрос `/api/admin/status` раз в 5 с только при видимой вкладке. В `routes/admin` у каждого
  раздела - шапка (что в нём и что можно сделать), в меню - подпись под пунктом.
- Невидимый текст: `.role.host` («Хост», People) и `.rec` («рекомендуем», Access) - белое на белом
  (`--on-accent` в теме белый); теперь тёмный текст.
- Проверка вёрстки `e2e/util.ts expectClean` ловит текст цвета фона.
- Тест Codex `metadata-loading`: на телефоне название есть и в заголовке кадра, и в карточке -
  проверяется заголовок первого уровня.

## Проверено (с изменениями Codex beta.16-17)

- fmt, clippy `-D warnings`, `cargo test -p fsfy-server`; Svelte check 0/0; Vitest 18; build.
- Playwright phone/tablet/desktop/iphone-webkit: 318 passed, 30 skipped, 0 failed - со строгой
  проверкой (пересечения, за краем, невидимый текст) на всех страницах из `layout.spec.ts`.
- Вручную: «Обзор» управления на 1440×900 и 375×812, «Люди» на телефоне.
