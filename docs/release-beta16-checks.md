# Nova 1.0.0-beta.16

24 октября 2026. Дополнение к beta.15; последние изменения интерфейса и трейлеров сохранены.

## Источники

- Lordfilm и Gidonline участвуют в поиске видео в Nova. Используются формы поиска самих сайтов,
  а затем проверяется H1 карточки, год и наличие встроенного плеера. Для известной карточки Nova
  название и год должны совпасть. Страницы сериалов не выдаются как фильм или отдельная серия.
- Lordfilm: адрес gz перенаправляется на актуальный поддомен; поиск отправляется после
  перенаправления. Импорт каталога тоже использует конечный URL для относительных ссылок.
- Kinoklass: добавлена кнопка адреса в импорте и распознавание ссылок, но сайт отвечает 403.
  Поддерживаемая форма поиска не обнаружена; рабочая интеграция воспроизведения не заявляется.
- Общий кэш поиска, лимит четырёх задач, таймаут сайта 20 секунд, максимум восемь проверяемых
  карточек и две параллельные загрузки на поиск. Неизвестные язык и качество не выдумываются.
- Сохраняется запрет внутренних IP/DNS и ограничение ответа страницы 4 MiB.

## Проверка на реальных сайтах

Изолированная временная база: поиск «Гарри Поттер и философский камень» на Gidonline и Lordfilm,
совпадение с 2001 годом, сохранение ссылки и получение URL видеопотока через API Nova - прошли.
Лог: target/beta16-live-sites.log. Полный просмотр, декодирование на iPhone и наличие русской
дорожки для каждого фильма этим тестом не подтверждаются.

## Ограничения

Это поиск по запросу и прежний ограниченный импорт страниц, не зеркало всего каталога.
Автоматический выбор серий с этих сайтов не реализован. Доступность зависит от сайтов.
Java остаётся отдельным незавершённым preview; установщик использует Rust-сервер.
Установленное приложение, рабочая база и настройки туннеля при проверках не изменяются.

## Автоматические проверки

- cargo test: 85 пройдено, 9 внешних проверок пропущены по ignore; отдельно запущенный живой
  тест поиска и разрешения потоков двух сайтов пройден.
- clippy all-targets: без предупреждений.
- Svelte check: 0 ошибок и предупреждений; 18 unit-тестов; production build.
- Playwright: 4 проверки на Chromium phone/desktop - выбор сайта импорта, отчёт и вёрстка,
  быстрый результат поиска появляется до ответа медленного провайдера.
- Логи проверок: target/beta16-*.log. Это не проверка всего ассортимента сайтов и не тест
  50 одновременно смотрящих видео через внешний интернет-канал.
