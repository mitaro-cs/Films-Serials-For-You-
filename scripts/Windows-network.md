# Сеть Nova на Windows

При проверке блокирующие политики брандмауэра организации не обнаружены:
Domain, Private и Public включены, локальные правила не запрещены (`NotConfigured`).
Надпись в системном окне сама по себе не определяет причину ограничения.
Политики Defender, обновлений и остальных компонентов не сбрасываются.

Для доступа к Nova с других устройств домашней сети откройте PowerShell от администратора:

```powershell
& 'C:\Maison\Nova\scripts\Enable-NovaFirewall.ps1' -Program 'C:\Maison\Nova\target\release\fsfy-desktop.exe'
```

Укажите фактический путь к приложению (не к установщику). Для нестандартного порта добавьте `-Port`.
Скрипт сначала экспортирует резервную копию брандмауэра, затем разрешает входящие TCP-соединения
только для приложения Nova, только в частном профиле и только из локальной подсети.
Сеть должна быть отмечена как частная в настройках Windows.

Удалить созданное правило:

```powershell
& 'C:\Maison\Nova\scripts\Enable-NovaFirewall.ps1' -Program 'C:\Maison\Nova\target\release\fsfy-desktop.exe' -Undo
```

Скрипт подготовлен, но автоматически не применён. Он не открывает доступ к тестовым EXE.
