# Nova: перенос сервера на Java

**Это самостоятельный Java preview, а не готовая замена сервера приложения. Полный перенос ещё не закончен.** Веб-интерфейс Svelte/TypeScript сохранён. Java не запускает и не проксирует Rust: перенесённые функции выполняются на JVM; остальные API явно возвращают 501.

Работают: HTTP-сервер на виртуальных потоках, статические файлы интерфейса и защищённые изображения, SQLite с 18 исходными миграциями, вход/выход и сессии, проверка существующих Argon2id-паролей, изменение профиля и пароля, управление аккаунтами и сброс пароля зрителя с отзывом сессий. Список участников учитывает внешние просмотры без дублей, отзывы, состояние дружбы, русский поиск и скрытие отключённых аккаунтов. Запросы дружбы, принятие встречной заявки и удаление дружбы выполняются атомарно. Перенесены локальный каталог, фильтры, русский поиск, оценки, статусы и место продолжения, прогресс и сезонные отметки заставки/титров, Range-раздача файлов с ограниченным буфером. Кеш локализации серий, комнаты с SSE, упорядоченные команды, чат и реакции также работают.

Не перенесены: главная и полная страница произведения, загрузка метаданных, поиск и разрешение внешних источников, HLS/ffmpeg/субтитры, общие списки и социальные функции, приглашения и голос, большая часть администрирования, локальное восстановление доступа хоста и почтовые функции, CloudPub, ночной режим через оболочку, запуск через Tauri и упаковка JRE. Полный перечень: [api-migration.csv](api-migration.csv). На 23 октября: 27 маршрутов перенесены, 3 частично, 109 ожидают переноса. С учётом импорта сайтов — всего 139 маршрутов.

Проверены HTTP-запросы с реальными сессиями, права зрителя/хоста, отзыв доступа после сброса пароля и блокировки, поиск и фильтры каталога, прогресс и титры, скрытые файлы, Range/416/скачивание и 50 параллельных небольших диапазонов. Модель комнаты проверена с 50 подписчиками и 50 одновременными командами. Это **не** проверка 50 одновременно воспроизводящих видео устройств и не замена нагрузочного испытания полноценного Java-сервера. Схема базы и формат хешей сессий сохранены.

## Сборка и проверка

Нужен JDK 25 (`JAVA_HOME` либо локальный `../tools/java/runtime`). Зависимости в `lib/`, версии и SHA-256 — в `dependencies.lock.json`. Никакая общая Java в Windows не устанавливается.

```powershell
.\server-java\build.ps1
```

Сборка: `build/nova-server.jar`; компиляция с `-Xlint:all -Werror`, затем автономные проверки на отдельной временной базе. Проверяется также хеш пароля, созданный Rust Argon2id. Для локальных сокетов Java на Windows задан отдельный короткий каталог `build/sockets`, чтобы не зависеть от проблем пути системного TEMP.

```powershell
.\server-java\run.ps1 -DatabasePath C:\Maison\Nova\target\java-preview\nova.db -Port 8090
```

Использовать отдельную тестовую базу или её копию при остановленном приложении. Не запускать оба сервера на основной базе. Новая пустая база пока не имеет мастера создания хоста: это часть ещё не перенесённой интеграции оболочки. Проверки сами создают тестовые аккаунты.

`GET /api/health` сообщает `runtime: java` и `migrationComplete: false`. Основной установщик пока содержит Rust-сервер; Java preview в него не подменяется до переноса и проверки всего API.
